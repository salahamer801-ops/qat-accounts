# حسابات القات 🌿

تطبيق لإدارة الحسابات اليومية ومزارع القات — مبيعات، مصروفات، ديون، وتقارير صافي الربح لكل مزرعة.

## المميزات
- تسجيل مبيعات القات (نقد / آجل مع اسم المدين)
- تسجيل مصروفات المزرعة (ديزل، ماء، بودرة، أسمدة، نفقة)
- حسابات يومية عامة (وارد / مصروف / دين)
- تقارير صافي الربح حسب المزرعة والفترة
- تصدير Excel وتقرير PDF
- دعم العملات: ريال يمني (YER)، ريال سعودي (SAR)، دولار (USD)
- واجهة عربية RTL مع وضع ليلي
- يعمل بدون إنترنت (PWA) وقابل للتحويل لتطبيق أندرويد عبر Capacitor

## التقنيات
Vite + React + TypeScript + Tailwind CSS + Capacitor

## التشغيل محلياً

